Naming and data convention

Each component root class and stylesheet shares one name. Visible data elements keep a stable value separate from localized wording.

Card
card, card.css
Learner space
learner-space, learner-space.css
User action
user-action, user-action.css
Learning group
learning-group, learning-group.css

A capability value declares what the Card may request. It does not declare device availability, permission, consent, or authorization.
