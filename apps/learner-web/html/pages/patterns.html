Markup investigation

Card template catalogue

Four inert templates describe the reusable Card structure. The expanded English and Hindi specimens show the expected HTML without using JavaScript or defining a final content schema.

Naming and data convention

Each template, root class, and stylesheet shares one component name. Visible data elements keep a stable value separate from localized wording.

Card
template-card, card, card.css
Learner space
template-learner-space, learner-space, learner-space.css
User action
template-user-action, user-action, user-action.css
Learning group
template-learning-group, learning-group, learning-group.css

A capability value declares what the Card may request. It does not declare device availability, permission, consent, or authorization.

Reusable structure

Inert templates

The templates remain in the document for inspection and automated tests. Their placeholder IDs must become unique when an instance is produced.

Expanded specimens

These Cards are written out as ordinary semantic HTML so their layout and language metadata can be reviewed without an initializer.
